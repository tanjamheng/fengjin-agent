## 游戏内属性

- **战斗属性**：风
- **命途**：记忆
- **忆灵**：小伊卡

### 核心机制

风堇是一名能召唤忆灵「小伊卡」并提高我方全体生命上限的回复型角色。小伊卡会自动为生命值降低的队友提供治疗，并基于累计治疗量对敌方造成伤害。

---

### 技能详情（以 10 级技能数据为准）

#### 普攻：当微风轻吻云沫

| 项目 | 内容 |
|------|------|
| 类型 | 单攻 |
| 能量恢复 | 20 |
| 削韧值 | 10 |
| 效果 | 对指定敌方单体造成等同于风堇 50% 生命上限的风属性伤害 |

#### 战技：爱在虹光洒落时

| 项目 | 内容 |
|------|------|
| 类型 | 回复 |
| 能量恢复 | 30 |
| 效果 | 召唤忆灵小伊卡，为除小伊卡以外的我方全体目标回复等同于风堇 8% 生命上限 + 160 的生命值。为小伊卡回复等同于风堇 10% 生命上限 + 200 的生命值 |

#### 天赋：疗愈世间的晨曦

- 忆灵小伊卡初始拥有等同于风堇 50% 生命上限的生命上限。
- 风堇或小伊卡提供治疗时，小伊卡造成的伤害提高 80%，持续 2 回合，最多可叠加 3 层。

#### 终结技：飞入晨昏的我们

| 项目 | 内容 |
|------|------|
| 类型 | 回复 |
| 能量消耗 | 140 |
| 效果 | 召唤忆灵小伊卡，为除小伊卡以外的我方全体目标回复等同于风堇 10% 生命上限 + 200 的生命值，为小伊卡回复等同于风堇 12% 生命上限 + 240 的生命值。风堇进入【雨过天晴】状态，持续 3 回合。处于【雨过天晴】状态时，我方全体目标生命上限提高 30% + 600 点 |

#### 忆灵技：乌云乌云快走开！

| 项目 | 内容 |
|------|------|
| 类型 | 群攻 |
| 效果 | 对敌方全体造成等同于本场战斗风堇、小伊卡累计治疗数值 28% + 我方小队其他目标累计治疗数值 11% 的风属性伤害并清空累计治疗数值的 50% |

#### 忆灵天赋：牵起晴空的手

- 小伊卡免疫所有负面状态。
- 当我方目标的生命值降低时，小伊卡将消耗自身生命值为该目标回复基于风堇生命上限的生命值。

### 专属光锥：愿虹光永驻天空

使装备者的速度提高 **18% / 21% / 24% / 27% / 30%**。

装备者施放普攻、战技和终结技时消耗我方全体等同于当前生命值 **1% / 1.2% / 1.5% / 1.7% / 2%** 的生命值，并使装备者的忆灵下一次攻击后额外对攻击目标造成 1 次等同于 **250% / 312.5% / 375% / 437.5% / 500%** 生命值消耗总量的基于装备者的忆灵属性的附加伤害，随后清空生命值消耗总量。

装备者的忆灵施放忆灵技时，使敌方全体受到的伤害提高 **18.0% / 22.5% / 27.0% / 31.5% / 36.0%**，持续 2 回合。同类效果无法叠加。
