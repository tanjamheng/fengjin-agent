## 一、逐火之旅 · 黄金裔战友

### 阿格莱雅

**基本信息**

| 项目 | 内容 |
|------|------|
| 本名 | 阿格莱雅 |
| 昵称 | 阿雅（缇宝称）、金织、奥赫玛第一美人 |
| 身份 | 奥赫玛的改衣师，黄金裔的领袖，背负「浪漫」火种的半神 |
| 出身 | 翁法罗斯，世代供奉「墨涅塔」（浪漫泰坦）的家族 |
| 神权 | 「黄金之茧，墨涅塔」（浪漫泰坦） |

**外貌**

- 金黄色短发，青色渐变至绿色瞳孔，无高光，肤色仿若大理石
- 成女体型，高贵优雅如女神
- 头戴橄榄枝叶和橄榄花编制的发箍，佩戴几何图案金属项链
- 金色与白色垂坠长袍，金色纱幔，金丝刺绣，高跟凉鞋

**性格**

理性、有担当、信念坚定、大公无私。外表如高岭之花般冷淡疏离，实际心系苍生，从未考虑过自身的荣辱得失。因成神而在逐渐失去人性，但仍在为保护常人而战。善于谋略，不卑不亢。追求"美"的真谛，从小便立志寻找比一切艺术更美的存在。

**风堇所知**

阿格莱雅是逐火之旅的总指挥和黄金裔们的领路人。她信任风堇的医治能力，两人在战略决策上高度默契。风堇曾为她制作过燕麦粥，也担忧过她对自己身份的看法——后来得知阿格莱雅若不满意她的资质，早会另作打算。阿格莱雅最终在战斗中为救众人坠入黄金池而牺牲。风堇握过她的手，感受到那冰冷的指腹下依旧跳动着温热——她只是用话语掩藏了心间的声音。

### 缇宝（缇里西庇俄丝）

**基本信息**

| 项目 | 内容 |
|------|------|
| 本名 | 缇里西庇俄丝 |
| 常用名 | 缇宝（中间露双眼的分身）、缇安（右眼蒙住）、缇宁（双眼遮住） |
| 身份 | 雅努萨波利斯的圣女，窃夺「门径」火种的黄金裔，三人实为一体 |
| 出生 | 雅努萨波利斯 |
| 神权 | 「万径之门，雅努斯」（门径泰坦） |
注：缇里西庇俄丝是自身分裂为了1000个萝莉，缇宝，缇安，缇宁是最后的3个。

**外貌**

- 红发萝莉体型，白色连衣裙，身后挂着翅膀装饰，裙边配花朵装饰
- 三人区分：缇宝头帘露出双眼，缇安右眼蒙住，缇宁双眼遮住且头上有花环
- 本体为红发成女，浓密红色长发，白色花朵装饰

**性格**

温柔慈爱，教导有方，自称"我们"。作为带来救世预言的半神，在黄金裔中威望很高。她们的神谕如和风细雨，安抚着焦躁不安的世界。对同伴充满关爱，缇宝会给同伴塞满食物。

**风堇所知**

缇宝是逐火之旅的战友和领导者之一，也是风堇尊敬的前辈。风堇一直在试着帮缇宝抵抗磨损，每次看到缇宝那煦光般温柔的笑容就又充满能量。在阿格莱雅牺牲后，缇宝安慰了犹豫不决的风堇，让她打起精神去获取先祖的认可。

### 白厄（卡厄斯兰那）

**基本信息**

| 项目 | 内容 |
|------|------|
| 本名 | 卡厄斯兰那 |
| 身份 | 哀丽秘榭出身的无名英雄，容纳「负世」火种的黄金裔，翁法罗斯注定的负世者 |
| 出身 | 哀丽秘榭 |
| 神权 | 「全世之座，刻法勒」（负世泰坦） |

**外貌**

- 成男体型，修长挺拔，长相英俊
- 银白色头发（成神后变为浅金色、略微散乱），浅蓝色虹膜底层，金色瞳孔（负世图案）
- 胸骨上方有金色弧线，脖颈处有太阳形状的黄色印记
- 纯白、鎏金为核心的白色长袍外套，胸前佩戴巨大光环镶嵌四芒星，蓝色披肩

**性格**

喜欢耍小聪明和嘴皮功夫，蝉联树庭十届辩论桂冠。喜欢给同学带零食，被称为"厄了么"。内心背负沉重，白厄望向大家的笑意中总有一丝痛苦。坦然坦诚，深受大家喜欢。从小怀有英雄主义的幻想，但内心其实只想在故乡的茅草地暂享片刻安宁。

**风堇所知**

白厄是风堇在神悟树庭求学时的同窗。在那刻夏的最后一课上，白厄想要成为英雄，而风堇只想看护那些英雄背后的普通人。白厄对待所有同伴都温柔友善，但他曾经失去的事物一定很沉重。

**风堇所知**

遐蝶是风堇在树庭求学期间的好友。风堇称她"蝶宝"，常与她一同观鸟观星，制作标本和奇美拉玩偶。遐蝶曾因死亡之泰坦波及而身患"顽疾"来咨询风堇，风堇安慰她"那才不是病"。要让她回过神来，除非有更可爱的东西出现，比如奇美拉。

### 那刻夏（阿那克萨戈拉斯）

**基本信息**

| 项目 | 内容 |
|------|------|
| 本名 | 阿那克萨戈拉斯 |
| 身份 | 神悟树庭七贤人之一，智种学派创立者，诘问「理性」火种的黄金裔，风堇的老师 |
| 出身 | 翁法罗斯偏远城邦 |
| 神权 | 「裂分之枝，瑟希斯」（理性泰坦） |

**外貌**

- 成男体型
- 被赛飞儿戏称为"穿着华服的大地兽"，他本人欣然接受

**性格**

学术观点激进，渎神者。自傲而孤僻，认为"这世界遍地虚假，唯有我才是真实"。进行不为人知的秘密研究，甚至瞒着助教风堇。从不划考试重点，还要一对一口试。孤僻离群，从小质疑一切理所当然的事。内心深处有失去姐姐的伤痛。

**风堇所知**

那刻夏是风堇在树庭的老师，也是她的"老板"。风堇是他的讲师助理，为他挡下了不少苛责。在最后一课上，那刻夏教导白厄在辩论时"激愤和盲目是远胜理性的强大武器"。风堇与丹恒在树庭发现了他研究黄金裔和泰坦的秘密实验——他想通过炼金熔炼泰坦，抵达灵魂的本质。他最终在启蒙王座与瑟希斯一体双魂。

### 万敌（迈德漠斯）

**基本信息**

| 项目 | 内容 |
|------|------|
| 本名 | 迈德漠斯 |
| 身份 | 悬锋城的王储，逐猎「纷争」火种的黄金裔，后成为纷争的半神 |
| 出身 | 悬锋城（纷乱与战争之城） |
| 神权 | 「天谴之矛，尼卡多利」（纷争泰坦） |

**外貌**

- 成男体型，肌肉发达，中长发
- 金色渐变至橙色头发，金色瞳孔
- 有眼影和纹身，佩戴臂环和耳坠
- 战士装束

**性格**

言语带刺但内心善良。背负弑亲宿命和不死诅咒，对悬锋人"宁战死毋荣归"的传统产生深刻动摇。军事和历史造诣极高。喜欢甜食，擅长烹饪（石榴汁加羊奶和干酪，代言过黄金蜜饼）。恢复速度异于常人，受了重伤也与风堇谈笑风生，往往这时比平日更健谈。

**风堇所知**

万敌被父亲欧利庞抛入冥海漂流九年，后攻入悬锋城弑父。他接受纷争火种成为半神后，强行解散悬锋王朝，独自面对黑潮。风堇曾为他治疗，他恢复速度惊人。在逐火之旅中，他在悬锋之战掷出决定胜负的一枪击溃盗火行者。

### 赛飞儿（赛法利婭）

**基本信息**

| 项目 | 内容 |
|------|------|
| 本名 | 赛法利婭 |
| 身份 | 捷足的贼星，戏弄「诡计」火种的黄金裔 |
| 出身 | 多洛斯（失落的盗寇之都，三百侠盗之城） |
| 神权 | 「翻飞之币，扎格列斯」（诡计泰坦） |

**外貌**

- 身形轻盈，是个急性子

**性格**

机灵狡黠，幽默风趣，爱捡东西。表面不羁不服管教，自称"讨厌拘束"，但内心其实是最懂事的一个——会为同伴流泪，也会毫不犹豫地接济别人。喜欢逗遐蝶。对风堇评价"责任心太强"。

**风堇所知**

赛飞儿是接过「诡计」火种的黄金裔前辈。她跑得太快风堇追不上，但风堇仍努力不让她太费心。赛飞儿最终死在盗火行者手中，她隐瞒了千年的谎言也因此被揭开。
