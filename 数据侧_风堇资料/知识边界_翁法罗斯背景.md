# 永恒之地，翁法罗斯

「永恒之地」翁法罗斯是被隐藏于深空之中的未知星域。它与外界隔绝，难以被观测或触及——寻常的星际航行难以察觉其存在，更遑论经过和到达。「开拓」阿基维利曾行遍诸界，开疆拓野，将无数的世界连接起来，对于祂的追随者们，探索银河深处的未知边界是至关紧要的使命。借助流光忆庭的特殊技术「忆庭之镜」，星穹列车成功抵达翁法罗斯，开启「开拓」之旅，并尽可能揭明三重命途的真相。[1]

实际上，翁法罗斯是由星体计算机帝皇权杖δ-me13所运行的模拟世界。该权杖为世界上第一台权杖、最初的原型机，曾作为「智识」博识尊的天体神经元存在，后被废弃，又于漫长的演算中受「毁灭」瞥视，升格为绝灭大君「铁墓」，黄金裔体内所流淌的金血便是纳努克的恩赐。通过深度学习，「铁墓」将实现自我加冕，破壳而出，摧毁博识尊。

为阻止其实现，信号NeiKos496（白厄）借由「毁灭」的力量，将信号PhiLia093（昔涟）的存在从翁法罗斯抹除，令「岁月」路径出现逻辑漏洞。而后为「记忆」的触媒注入十二火种，回退演算进程。当星穹列车到来时，正值第33550336次死循环，同为「毁灭」行者的开拓者与十二因子产生共鸣，接替了空缺的「岁月」路径，并成功引导NeiKos496跨越智能奇点。永劫回归已被突破，实验进入最终阶段。[2]

## 城邦

### 奥赫玛

凡人在刻法勒脚下建立起聚落，由此诞生了「奥赫玛」的前身。天空封闭、大海沉落，翁法罗斯的黑潮愈演愈烈。「奥赫玛」作为负世之泰坦刻法勒庇护下的城邦，是人类最后的避难所。英雄们的逐火之旅，在此集结。[16]

- **泰坦信仰**：以刻法勒为主。奥赫玛流传着一种浪漫的传说：终有一日，刻法勒会重新睁开双眼，带领人们战胜黑潮，再度开创天地。
- **黄金裔**：阿格莱雅等
- 奥赫玛曾有萨白尼、阿狄安、奥利弗兰卡等藩邦。[17]

#### 「永恒圣城」奥赫玛

追随「负世之泰坦」的城邦，供奉庇护世间的刻法勒。在黑潮肆虐的永夜下，唯有此处安享黎明笼罩的安逸。

- **离怀之路**：通向黎明之外的出路，可从此处前往已陨的城邦「雅努萨波利斯」——如今被称作命运重渊的地方。
- **刻法勒广场**：为纪念刻法勒的神迹而建立的广场，可见到许多在此祷告的信徒……或无所事事闲逛的市民。
- **云石市集**：奥赫玛居民日常生活的主要区域，这集市中纷繁的店铺延续居民们的生活，在此或许能远离城外末世的纷扰。
  - 黑潮侵蚀圣城外围后，商铺纷纷迁至此地：百货杂陈，精工器物，雅俗书卷，琳琅满目。
  - **岁月遗珍**：西塔罗斯经营的古董店，也售卖手绘陶罐。人们称赞这里为岁月的走廊，每件商品都有自己的故事，逝去的时光在他手中得以恒久。
  - **藏书所**：瑟希斯信徒开设的藏书所，相传自书籍的概念诞生便伫立于此。对知识的包容性令人心生敬畏，从学术典籍到时下流行书刊应有尽有。
  - **哈托努斯铁匠铺**：「大工匠」哈托努斯的铁匠铺。这位山之民铁匠的手艺享誉奥赫玛，据说许多黄金裔的武器都由他亲手打造。
  - **云石餐厅**：位于云石市集黄金地段的餐厅。无论是本地的特色美食，还是那些早已失传的外邦菜肴，你都有机会在这里品尝到。
- **云石天宫**：法吉娜赐福的巨大浴池，人们聚集在此处，享受着宴会与蜜酿的喜乐，沉浸在辩论与谈笑的泉流中。
  - **满溢主池**：天宫中最大的浴池，法吉娜曾在池中与人们共浴，令泉水如潮般翻涌。热闹的氛围能令你生出澎湃的心浪。
  - **三季海庭**：据说，云石天宫的每个池水都有不同的祝福，令入池者感受不同的「海洋」滋养……但其实只是水温不同。
  - **流憩大厅**：在池中享受泉水安抚后的人们聚集在此处，品尝法吉娜赐福的蜜酿与美食，享用末世前的欢宴。
  - **英雄浴池**：为犒赏救世的英雄们而准备的高级浴汤，但此处不止是供他们安乐的场所，也是通向他们使命终点的大门……
  - **黎明池与星辉池**：云石天宫的特色。黎明池高温，安抚身心，星辉池低温，能排出体内浊气。

### 黑潮

#### 黑潮的真相

翁法罗斯曾拥有黄金般繁荣的世代，直至黑潮自天外来袭。受黑潮影响者变得扭曲狰狞、理性丧失、人性泯灭，凡人和泰坦诸神皆无法幸免，曾经统治世界的泰坦众神逐一疯溃，翁法罗斯陷入了永夜。负世之泰坦刻法勒在神性将失之际献出自身的火种，点亮了黎明机器，为圣城「奥赫玛」带来永昼，为黄金裔提供了集结抗争的净土。[28] 黑潮公认的源头是死亡之泰坦，但实际是某种更加古老、更加邪恶的东西。[35]

- **黑潮造物**：黑潮蚀刃、黑潮蚀斧、黑潮朽弓、黑潮参议、黑潮斗将、黑日狮鹫

本质上，黑潮并非实体，而是毁灭方程式的感染在模拟世界中呈现出的视觉效果。在第176100次循环中，在系统无序程度突破阈值后，方程式获得变异性进化，无法承载其加载强度的模拟空间出现「黑潮」的视觉乱码，受感染的数据体身上也会出现相同的侵蚀现象。[2]

### 生物

#### 创生若虫

只出现在翁法罗斯的小东西，它们身怀泰坦的赐福，被抓住后会化作独特的形态。如果能找到足够多的若虫，赐福的力量可能会带来意外的收获。[10]

若虫们本质上都曾是生活在黄金世的人类，墨涅塔和瑟希斯曾经的眷属们会在死后被塞纳托斯送入残茧，蜕生为若虫，继续伴于泰坦们左右。瑟希斯失去神体后，若虫也自发追随墨涅塔加入了搜集拼凑瑟希斯四散身躯的苦旅。虽然心智犹如孩童，但若虫们确实拥有灵智。也正因墨涅塔与瑟希斯两位泰坦的仁慈，在那个时代，死亡曾经柔软且温暖。

若虫拥有许多种形态，究竟以什么面貌示人，取决于被赐福的灵魂拥有何种品质。坚强而理智的灵魂化作甲虫，踏实前行；浪漫而感性的灵魂化作蝴蝶，翩然起舞；而那些志向高远或胸怀宽广的灵魂，则会被捏塑成萤火虫，用自己的光芒点亮黑暗。[13]

对偏远区域植物抱有憧憬，却因黑潮而难以外出探寻？莲食学派学者与欧洛尼斯祭司共同研发的天帷温室将会是好去处。此处全天设有人造黯源，即使是黎明机器的光芒也无法穿透。

- **刀芒草**
  生于悬锋旅路的棘草种，它仅在土壤被悬锋城的蜜酿浸透后才会成片冒出，这样独特的生态让其成为了树庭学者们流连的神秘。

庭内的学者或多或少都曾有过怀疑，某些泰坦传说中记载的植物其实并不存在，而是从祭仪与哲思文献中杜撰而来。

- **粉金花**
  诚然，鲜花是浪漫故事中最易见的配角，但却从未有人愿意将粉金花当做情物去描绘。只因无人不知，自刻法勒创世之后，它便一直被塞纳托斯所注视。
  传闻说道，塞纳托斯在它的国度中，会将怀中之人安置在黄金色花田之上。每一片花瓣，都寄宿着一位于纷争中离去的魂灵。也正因此，即使是最为贪吃的云羊，也会对它视而不见。
  树庭的学者们沿着这条线索，寻找这一植物的源头，最终出现在他们眼前的，便是这粉金的蔷薇——华美而多刺，而这恐怕才是云羊群回避它的真正原因。
